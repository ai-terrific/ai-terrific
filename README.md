# 🚀 About Me

I'm a **Senior Software Engineer with 10+ years of experience** building production-grade software across **frontend, backend, cloud, databases, DevOps, distributed systems, and infrastructure**.

My strongest engineering areas are **JavaScript, TypeScript, Go, and Python**, while I also work extensively with Java, C#, Rust, Solidity, Dart, and other modern technologies.

I specialize in **full-stack engineering and backend systems**, with experience designing applications from the UI layer all the way through APIs, databases, cloud infrastructure, CI/CD, and production operations.

I enjoy solving difficult engineering problems, designing clean architectures, improving system performance, automating workflows, and building software that is reliable at scale.
